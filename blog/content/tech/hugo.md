## hugo可以用来部署个人博客网站

> The Hugo development server optimizes for refreshes with content changes. Theme changes affecting multiple files are error-prone when reloading. If you change a theme’s contents, it’s possible that caching in the browser or incrementally building with the development server will get in the way of viewing updates. Restart the dev server, clear the browser cache, and use hugo server --noHTTPCache --disableFastRender to help in these cases.

如果要清除缓存，执行以下命令：`hugo server --noHTTPCache --disableFastRender`

### 用hugo可以实现的功能

- 标签分类
